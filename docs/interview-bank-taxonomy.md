# 八股题库分类

题库使用固定的 `domain -> topic -> subtopic` 层级。当前一级领域为：`agent`、`rag`、`llm_application`、`python`、`network`、`ai_engineering`。

重点覆盖 Agent 工作流、Tool / Function Calling、MCP、RAG、Memory、Planning、多 Agent、评估和安全；Python / asyncio / FastAPI / Pydantic；HTTP、SSE、WebSocket；以及 AI 应用的结构化输出、重试、流式、可观测性、部署和成本控制。前端八股题不在本题库范围内。

每题必须具备来源、至少三个参考要点、至少两个常见错误和权重和为 100 的评分 rubric。所有由 AI 整理或生成的题目默认 `pending` 且 `verified_by_human=false`；生产训练查询只返回 `verified`。
