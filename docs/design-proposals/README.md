# 八股训练视觉方向

这些文件是独立、静态的设计预览，不会接入任何正式路由，也不依赖 API 或本地环境变量。

- `A-editorial-focus.html`：编辑阅读感。题目与回答是主角，适合深度阅读和复述。
- `B-command-workspace.html`：高密度工作台。适合频繁训练、审核和管理题集。
- `C-quiet-premium.html`：低亮度中性色。适合长时间、低干扰的个人学习节奏。
- `D-data-learning-studio.html`：学习数据工作室。首页更突出连续学习、领域分布和掌握度。

在浏览器中直接打开任一 HTML 文件，或从本目录启动任意静态文件服务器即可预览。
