# 方向 A：雾绿延续

**一句话**：把现有浅绿调成更安静的雾感纸面；绿只用来提示可以继续、可以前进，不把学习做成仪表盘。

## 为什么先比较它

当前 demo 已有 `--canvas`、`--paper`、`--accent` 的浅绿基础。这条路线能低风险地保留熟悉感，并通过减少卡片、把统计移到下方、用细分隔线替代模块框，解决现有手机首页“统计先于任务”的问题。

## 候选 tokens

| 用途 | 值 | 使用原则 |
| --- | --- | --- |
| 画布 | `#EEF3EE` | 页面底色；仅有极轻颗粒，不使用渐变。 |
| 主表面 | `#FBFDFC` | 回答输入、继续上次和列表项。 |
| 柔和表面 | `#E3ECE5` | 示例、已说对内容、轻提示。 |
| 正文墨色 | `#1D2821` | 全部主要文字；不用低对比“淡灰字”代替正文。 |
| 次级文字 | `#617066` | 辅助说明、元信息。 |
| 分隔线 | `#C9D4CC` | 1 CSS px 细线；不做卡片堆叠。 |
| 主行动 | `#35664D` | 唯一实心主按钮、当前 tab、可继续状态。 |
| 主行动浅底 | `#DCEBE0` | 已说对、选中但非主按钮。 |
| 等待/提醒 | `#855E32` | 仅用于等待、到期提示，附文字。 |
| 失败 | `#9A4A43` / `#F5E9E6` | 错误文案与承载底色；绝不只靠红色说明失败。 |

## 字体与材质

- UI：`PingFang SC, -apple-system, BlinkMacSystemFont, "Noto Sans CJK SC", sans-serif`。正文不使用衬线，保证题意和输入易读。
- 标题：同一字体 Medium/Semibold；不在每屏使用大标题戏剧化排版。
- 材质：2–3% 的纸纤维/细噪点，只作用于大背景，文本和输入面保持清晰。
- 装饰：至多一个极细植物线条或文字符号；不放照片瀑布、AI 星光、渐变团块。

## 适合与风险

适合希望保留当前 demo 亲和感、同时把重心拉回“开始学习”的客户。风险是若绿色面积过大容易偏健康 App；实现时严格限制为一个主强调色、白色输入面与墨色正文。
