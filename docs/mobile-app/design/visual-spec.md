# 视觉 tokens 与组件规范：雾绿延续

**一句话**：把现有浅绿调成更安静的雾感纸面；绿只用来提示可以继续、可以前进，不把学习做成仪表盘。

## 最终设计意图

当前 demo 已有 `--canvas`、`--paper`、`--accent` 的浅绿基础。本规范保留熟悉感，并通过减少卡片、把统计移到下方、用细分隔线替代模块框，解决首页“统计先于任务”的问题。

## 颜色 tokens

| 用途 | 值 | 使用原则 |
| --- | --- | --- |
| `canvas` / 画布 | `#EEF3EE` | 页面底色；仅有极轻颗粒，不使用渐变。 |
| `surface` / 主表面 | `#FBFDFC` | 回答输入、继续上次和列表项。 |
| `surface-subtle` / 柔和表面 | `#E3ECE5` | 示例、已说对内容、轻提示。 |
| `ink` / 正文墨色 | `#1D2821` | 全部主要文字；不用低对比“淡灰字”代替正文。 |
| `ink-muted` / 次级文字 | `#617066` | 辅助说明、元信息。 |
| `rule` / 分隔线 | `#C9D4CC` | 1 CSS px 细线；不做卡片堆叠。 |
| `accent` / 主行动 | `#35664D` | 唯一实心主按钮、当前 tab、可继续状态。 |
| `accent-subtle` / 主行动浅底 | `#DCEBE0` | 已说对、选中但非主按钮。 |
| `warning` / 等待提醒 | `#855E32` | 仅用于等待、到期提示，附文字。 |
| `danger` / `danger-subtle` | `#9A4A43` / `#F5E9E6` | 错误文案与承载底色；绝不只靠红色说明失败。 |

## 字体与材质

- UI：`PingFang SC, -apple-system, BlinkMacSystemFont, "Noto Sans CJK SC", sans-serif`。正文不使用衬线，保证题意和输入易读。
- 标题：同一字体 Medium/Semibold；不在每屏使用大标题戏剧化排版。
- 材质：2–3% 的纸纤维/细噪点，只作用于大背景，文本和输入面保持清晰。
- 装饰：至多一个极细植物线条或文字符号；不放照片瀑布、AI 星光、渐变团块。

## 组件外观规则

| 组件 | 最终视觉规则 |
| --- | --- |
| 主按钮 | `accent` 实底、白字、14 px 圆角、52–56 px 高；每屏最多一个实心主按钮。按下只降低明度/轻缩放，不上渐变。 |
| 次级按钮 | `surface` 底 + `rule` 1 px 边；文字为 `accent`；与主按钮保持 12 px 间隔。 |
| 输入框 | `surface` 底 + `rule`；聚焦改为 2 px `accent` 边并有明确标签，允许纵向扩展。 |
| 列表行 | 平面白底或透明底，1 px 分隔；不再套一张张浮卡。整行 56 px 以上可触。 |
| 反馈块 | “已说对”用 `accent-subtle`；“待补充”保持白底 + 结构标题；失败用 `danger-subtle`。 |
| 底部导航 | 背景与画布同色/轻表面，当前项 `accent`；专注作答页完全隐藏。 |

## 禁止项

- 不增加第二个品牌主色，不扩大绿到大面积装饰背景。
- 不用渐变、玻璃、厚阴影、大药丸、彩色统计块、AI 星光或后台图表。
- 不用文字对比度不足的浅灰正文；不以颜色作为唯一状态说明。
