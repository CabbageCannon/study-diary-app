# 方向 B：暖白纸张

**一句话**：像一本可随手翻开的学习册，暖象牙纸、炭黑文字与橄榄褐行动色，让内容本身成为视觉焦点。

## 为什么比较它

这条路线把“ins 感”放在纸张、留白与排版，而非照片墙或装饰性 AI 图形。日期可以得到一次克制的衬线强调，其余题意、输入、反馈仍是 iPhone 易读的系统中文。与现有浅绿相比，它的日常工具感更低、阅读仪式感更强。

## 候选 tokens

| 用途 | 值 | 使用原则 |
| --- | --- | --- |
| 画布 | `#F8F4EC` | 暖象牙纸底，极轻纸纹。 |
| 主表面 | `#FFFCF6` | 输入、继续上次和列表。 |
| 柔和表面 | `#F0E8D9` | 示例与次级归组。 |
| 正文炭黑 | `#29251F` | 题意和用户回答。 |
| 次级文字 | `#716B60` | 说明与时间。 |
| 分隔线 | `#D9D0C0` | 细横线、章节规则。 |
| 主行动 | `#596347` | 唯一实心主按钮与选择态。 |
| 主行动浅底 | `#E8E9D8` | 已说对、轻强调区。 |
| 反馈暖色 | `#9B6752` / `#F5E9E4` | 只表示需要处理的失败或待补充，不当品牌第二主色。 |

## 字体与材质

- UI：`PingFang SC, -apple-system, BlinkMacSystemFont, "Noto Sans CJK SC", sans-serif`。
- 装饰字：`Songti SC, STSong, "Noto Serif CJK SC", serif` 只允许用于“九月六日”一类日期/章节，最大 1 次/屏，且必须回退为系统字体。
- 材质：纸纹透明度最多 3%；不把纹理放到输入框、按钮、正文或状态条上。
- 装饰：细横线、章节编号、一个简洁书签式符号；避免复古贴纸和仿手账贴图。

## 适合与风险

适合把口述复盘当作每日安静练习的客户。风险是衬线字或暖色过多会牺牲手机可读性；因此它只装饰日期，反馈仍以结论文字、结构和图标形状区分。
