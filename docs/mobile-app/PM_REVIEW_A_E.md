## 退回 A 的修改

1. **统一逻辑尺寸与三倍导出。** 图稿声明 1170×2532 对应 390×844 CSS px，但正文 31–34 输出 px 仅约 10–11 CSS px，主按钮高度 116 输出 px 仅约 38.7 CSS px；规范要求正文 17px、按钮 52–56px。需统一坐标/倍数并重新排版，逐张检查全部图稿。
2. **复习分组与导航。** 「今天」分组中混入明天与其他日期；混合算法的复习页高亮八股入口。需明确日期分组和复习页来源/返回位置。
3. **保存与评估区分。** 只有收到保存成功结果才能显示已保存；保存失败与评估失败分别处理。本机草稿、服务端回答不是同一个状态。
4. **导出与交接细节。** 空复习页勾号导出为缺字符号；导航图标要指定现有 Phosphor 组件，避免占位符直接进入成品。修正失败文案和 PR 过期的分支说明、相对链接。

色彩方向不重新选择，保留客户选定的雾绿。A 已收到任务并开始修正。

## 退回 E 的修改

1. **生产请求路径阻塞。** `frontend/pwa-production.env.sample` 中 `VITE_API_BASE_URL=/api`，而调用端已传 `/api/...`，`client.ts` 直接拼接后成为 `/api/api/...`。同源基址应为空，配置与文档同步修正并验证实际生产请求。
2. **测试收集遗漏。** `test_time_utils.py` 有两个顶层测试函数，unittest 未收集。需要修正测试发现方式，让常规检查真正覆盖这两个用例。PM 手动验证通过不替代常规收集的修复。
3. **首次部署可执行性。** 迁移命令需加载与 systemd 一致的环境，否则可能操作默认库；首次证书签发需 HTTP 引导，不能先加载不存在的证书路径。修正“同域即无需访问码”的不准确说明。
4. **统一交接。** 修正 PR 正文的字面量换行；A 修订完成后，把最终设计纳入 `codex/mobile-integration` 并公布统一 SHA，暂不合并默认分支。

E 已收到任务并确认 API 前缀和测试收集问题属实，开始修正。
